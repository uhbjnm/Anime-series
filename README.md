# 长篇连载动漫（片名待定）

第一期 12 集 × 每集约 20 分钟。制作流程：大纲 → 剧本 → 分镜 → 角色定妆照 → 逐镜生成 → 配音配乐 → 合成核验，逐集推进。

## 目录结构

- `outline/` — 总大纲、分集大纲（主人提供方向，笨笨扩写）
- `scripts/` — 各集完整剧本
- `storyboards/` — 各集分镜表
- `characters/` — 角色设定与定妆照（全季基准，角色一致性的锚点）
- `scenes/` — 场景设定图
- `assets/` — 全季共用素材（配乐主题、片头片尾等）
- `episodes/epXX/` — 每集的制作区：`frames/` 分镜图、`clips/` 动态片段、`audio/` 配音与配乐、`work/` 合成工作文件

## 约定

- 角色定妆照一旦定版，不得随意更换；后续镜头一律以定妆照为基准生成。
- 成片逐镜核验（真实运动 + 配音全覆盖）通过后才交付。
- 每集完成打一个版本标签：`ep01-v1`、`ep01-v2`……
